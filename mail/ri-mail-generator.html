Google Docs 업무 템플릿

현재 테스트 버전은 Google Docs 1개 = 이메일 템플릿 1개 방식으로 동작합니다. Google OAuth 웹 클라이언트 ID와 Google Drive 템플릿 폴더는 앱에 기본값으로 포함되어 있어 별도 설정 파일을 연결할 필요가 없습니다. Google 연결 후 등록된 Drive 폴더의 템플릿을 바로 불러올 수 있습니다.

Google Docs 첫 줄을 제목: {{회의명}} 개최 안내처럼 작성하면 제목과 본문을 자동 분리합니다. [EMAIL_SUBJECT]와 [EMAIL_BODY] 구분자도 사용할 수 있습니다. Google Docs의 기본 글자 크기, 굵기, 기울임, 밑줄, 색상, 글꼴, 문단 정렬과 간격은 브라우저 최종본에서 가능한 범위까지 재현합니다. 앱은 Docs API 읽기 권한만 사용하며 원본 Google Docs를 수정하지 않습니다.

Google Docs 공유 주소를 직접 붙여넣는 방식과 기존 DOCX·HWPX·TXT·MD 직접 파일 선택도 함께 사용할 수 있습니다.

한국어 조사 자동 보정

{{이름}}은, {{담당자}}이, {{회사명}}을, {{장소}}으로처럼 템플릿 항목 바로 뒤에 조사가 붙어 있으면 최종 치환 단계에서 받침을 확인해 은/는, 이/가, 을/를, 과/와, 으로/로, 이랑/랑, 이라/라 등을 자동 보정합니다. 한 건 입력과 Excel/CSV 모든 행에 동일하게 적용하며 원본 템플릿 문구는 수정하지 않습니다. 한글 받침으로 확정할 수 없는 영문·숫자·기호 끝 값은 자동으로 추측하지 않고 조사 확인 필요 영역에만 표시하며, 사용자가 선택한 조사만 해당 출력에 적용합니다.

경량 AI 도우미와 원본 보호

AI 기능은 기본적으로 꺼져 있으며 사용자가 직접 켜고 실행할 때만 동작합니다. 의미 기반 열 이름 매칭과 메모에서 빈칸 후보 찾기는 다국어 MiniLM 양자화 모델을 사용하며, 최초 실행 시 약 120MB를 내려받고 이후에는 브라우저 캐시를 사용합니다. 최종 문서 점검은 규칙 기반이라 모델 다운로드 없이 바로 실행됩니다.

AI는 템플릿 전체 문맥과 각 항목 주변 문장을 읽을 수 있지만 원본 템플릿을 수정하지 않습니다. 원본 문장, {{항목}} 태그, DOCX/HWPX 문단·글자·표·이미지 구조는 읽기 대상으로만 사용합니다. AI의 쓰기 대상은 사용자가 직접 입력하는 필드값과 Excel/CSV 열 연결 정보로 제한하며, 메모에서 찾은 값도 자동 입력하지 않고 사용자가 적용을 누른 항목만 반영합니다.

네 가지 입력 방식

본문 입력은 문서 안의 {{항목}} 자체가 입력칸으로 바뀌어 실제 문장을 읽으면서 바로 값을 채우는 방식입니다. 표 입력은 같은 항목을 항목명·입력값 표로 정리해 한 화면에서 빠르게 작성할 때 사용합니다. 두 방식은 같은 값을 공유하므로 언제든 전환해도 입력 내용이 유지됩니다.

텍스트 붙여넣기와 파일 불러오기는 여러 건을 만드는 일괄 모드입니다. Excel에서 복사한 표·CSV 텍스트를 붙여넣거나 XLSX·XLS·CSV 파일을 불러오면 첫 행을 항목명으로 인식하고 두 번째 행부터 각 문서를 생성합니다.

DOCX·HWPX 서식 미리보기와 복사

DOCX/HWPX 템플릿을 불러오면 오른쪽 최종본에서 원본의 문단 정렬, 글자 크기, 굵게·기울임·밑줄, 글자색, 줄간격과 문단 간격 등을 브라우저에서 가능한 범위까지 근사 표시합니다. 서식 포함 복사는 지원되는 브라우저에서 HTML 서식과 일반 텍스트를 함께 클립보드에 넣어 Word, 메일 편집기 등에 붙여넣을 때 기본 서식이 최대한 따라가도록 처리합니다. 표·도형·이미지·복잡한 번호 매기기 등은 브라우저 미리보기에서 완전히 동일하지 않을 수 있으며, 실제 DOCX/HWPX 내보내기는 기존 원본 서식 유지 로직을 사용합니다.

TXT·MD까지 일괄 출력

일괄 작성에서는 HWPX·DOCX·TXT·MD 모두 개별 파일 ZIP과 한 파일 중 하나를 선택할 수 있습니다. HWPX·DOCX는 각 데이터 건을 새 페이지에서 시작하고, TXT는 긴 구분선, Markdown은 --- 구분선으로 각 건을 나눠 하나의 파일로 저장합니다.

사용 방법

  1. 템플릿의 바뀌는 부분을 {{이름}}, {{회사명}}, {{날짜}}처럼 표시합니다. 고유 항목은 최대 20개입니다.
  2. DOCX·HWPX·TXT·MD 템플릿을 불러온 뒤 본문 입력 또는 표 입력에서 한 건의 값을 채웁니다.
  3. 여러 건은 텍스트 붙여넣기에서 Excel 표를 그대로 복사해 붙여넣거나, 파일 불러오기에서 XLSX·XLS·CSV를 선택합니다. 첫 행은 항목명입니다.
  4. 오른쪽 최종본에서 이전·다음으로 각 행을 확인하고, 필요하면 서식 포함 복사로 현재 결과를 복사합니다.
  5. 일괄 내보내기는 HWPX·DOCX·TXT·MD 모두 개별 파일 ZIP 또는 한 파일을 지원합니다.
  6. 파일명 규칙에는 {{이름}} 같은 항목을 사용할 수 있고, {{번호}}는 001, 002, 003처럼 자동 증가합니다.

지원 형식과 서식

출력은 HWPX, DOCX, TXT, MD를 지원합니다. 직접 작성한 템플릿이나 다른 형식으로 변환하는 HWPX·DOCX에는 글자 크기, 줄 간격, 문단 간격, 문단 정렬을 적용합니다. DOCX/HWPX 원본을 같은 형식으로 내보낼 때는 해당 파일의 기존 서식을 우선 유지합니다. TXT와 MD는 텍스트 구조를 그대로 저장합니다. 일괄 모드에서는 HWPX·DOCX·TXT·MD 모두 개별 파일 ZIP 또는 하나의 결합 파일로 저장할 수 있습니다. HWPX·DOCX는 각 건을 새 페이지에서 시작하고 TXT·MD는 구분선을 넣어 이어 붙입니다.

DOCX·HWPX 원본 서식 유지

DOCX 또는 HWPX를 템플릿으로 불러오면 미리보기에서 문단 정렬, 글자 크기, 굵기, 글자색 등 읽을 수 있는 기본 서식을 근사 표시합니다. 실제로 같은 형식으로 내보낼 때는 문서를 새로 만들지 않고 원본 파일의 내부 구조를 그대로 복제한 뒤 {{항목}} 부분의 텍스트만 바꿉니다. 따라서 글꼴, 글자 크기, 색상, 문단 서식, 표, 이미지, 머리글·바닥글 등 원본 서식과 개체를 유지할 수 있습니다. DOCX 템플릿은 DOCX로, HWPX 템플릿은 HWPX로 내보낼 때 원본 서식 유지가 적용됩니다. 다른 형식으로 변환하면 상단에서 지정한 공통 문서 서식으로 새로 생성합니다.

원본 DOCX/HWPX를 불러온 뒤 왼쪽 템플릿 텍스트 자체를 직접 수정하면 원본 문서와 화면 텍스트의 위치 대응이 달라질 수 있으므로 서식 유지 모드가 자동으로 해제됩니다. 기존 {{항목}}에 값을 입력하거나 Excel/CSV 데이터만 연결하는 경우에는 원본 서식 유지 모드가 계속 적용됩니다.

같은 형식의 DOCX/HWPX 템플릿을 단일 문서로 결합할 때도 원본 본문 구조와 서식을 복제해 각 데이터 건을 새 페이지에서 시작하도록 처리합니다. DOCX의 머리글·바닥글 안에 {{항목}}이 있는 경우 단일 파일 구조상 첫 번째 데이터 행 값이 공통 적용될 수 있습니다.

데이터는 서버로 전송되나요?

아닙니다. 템플릿 읽기, Excel/CSV 파싱, 항목 치환, DOCX/HWPX 생성과 ZIP 묶기까지 모두 현재 브라우저 탭 안에서 처리합니다. 페이지를 닫거나 새로고침하면 작업 중인 데이터도 사라집니다.

참고: 구형 Word 바이너리 형식인 .doc은 지원하지 않습니다. Word 또는 Google Docs에서 .docx로 저장한 뒤 불러오면 됩니다. Excel 일괄 데이터는 첫 번째 시트를 사용합니다.
